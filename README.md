# Kapsule

### Vos applications, enfin bien organisées.

**Kapsule** est une application de bureau Windows conçue pour organiser,
lancer facilement et rapidement vos applications préférées depuis une
interface simple.

## ✨ Fonctionnalités

-   **Lancement rapide** --- accédez à vos applications sans devoir les
    chercher dans vos dossiers.
-   **Kapsules personnalisées** --- regroupez vos applications selon
    votre organisation.
-   **Favoris** --- retrouvez rapidement les outils que vous utilisez le
    plus.
-   **Recherche** --- trouvez plus facilement une application dans votre
    collection.
-   **Paramètres** --- personnalisez l'apparence et la langue de
    l'application.
-   **Mises à jour** --- Kapsule peut vérifier la disponibilité de
    nouvelles versions et proposer leur installation.
-   **Interface légère** --- une application de bureau conçue avec une
    interface moderne.

## 📥 Installation

### Installer la version Windows

1.  Ouvrez la page des [releases de Kapsule sur
    GitHub](https://github.com/HenriAku/Kapsule/releases).
2.  Téléchargez le fichier d'installation `.exe` de la version
    souhaitée.
3.  Ouvrez le fichier téléchargé et suivez les instructions affichées.
4.  Lancez Kapsule depuis le menu Démarrer ou le raccourci créé par
    l'installation.

> Téléchargez de préférence la dernière version publiée dans la section
> **Releases**. Ne téléchargez pas un fichier `.sig` ou `latest.json`
> pour installer l'application : ils servent au mécanisme de mise à
> jour.

## 🧰 Technologies utilisées

-   [React](https://react.dev/) --- interface utilisateur.
-   [TypeScript](https://www.typescriptlang.org/) --- code typé.
-   [Tailwind CSS](https://tailwindcss.com/) --- styles de l'interface.
-   [Rust](https://www.rust-lang.org/) --- partie native de
    l'application.
